# 📌 프로젝트 개요

**CafeBoo(카페부)** 는 카페인을 중심으로 **일상을 기록하고, 사람들과 연결되는 라이프로그 커뮤니티 서비스**입니다.  
하루의 커피 한 잔, 느낀 감정, 나만의 루틴까지.  
작은 기록들이 쌓여 **데이터로 나를 이해하는 공간**, 그게 바로 CafeBoo입니다.



### 왜 만들었을까?

현대인의 카페인 소비는 단순한 음료가 아닌 **루틴, 감정, 그리고 사람들과의 연결**을 의미합니다.

> “내 카페인 섭취는 건강할까? 과하지 않을까?”  
> “나랑 비슷한 루틴을 가진 사람은 어떤 하루를 보낼까?”  
> “커피챗에 가볍게 접근할 수 있는 플랫폼은 없을까?”

이런 질문들로부터 **CafeBoo**는 출발했습니다.



### 🌟 CafeBoo가 지향하는 방향

단순한 일상 기록 앱을 넘어,  
**기록 → 인사이트 → 연결**이라는 선순환을 통해  
작은 변화와 성장을 만들어가는 것이 우리의 목표입니다.

- ☕ **카페인 기록**: 오늘 마신 커피 기록을 남겨요  
- 📊 **카페인 루틴 분석**: 나만의 카페인 적정량을 분석하고 패턴을 데이터로 확인해요

## 🧱 아키텍처 구조

> 📌 상세한 다이어그램은 추후 첨부 예정입니다.

- 사용자는 **React 프론트엔드**를 통해 데이터 입력
- 입력된 데이터는 **Spring Boot API 서버**로 전달
- 서버는 **AI 모델과 DB**를 연동하여 결과 분석
- 채팅 기능은 별도 채팅 서버를 통해 처리되며, 메시지는 **Kafka**를 통해 브로드캐스트됩니다.
- **Redis**는 채팅방 상태, 접속 유저, 메시지 캐시 등을 관리합니다.
- 분석 결과는 프론트엔드에 시각적으로 표시
- 전체 인프라는 **Docker 기반**, **AWS 환경**에서 구동
- **GitHub Actions**를 통한 자동화된 빌드 및 배포
- **Prometheus**가 각 서비스의 메트릭을 수집하고, **Grafana**는 이를 시각화하여 성능 모니터링 대시보드를 제공합니다.
